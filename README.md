## How to read the results

- **Exact connector/package** means the same branded resource or first-party skill package was verified.
- **Functional workflow/connector** means it can achieve a similar user outcome but is not API-, data-, control-, or methodology-equivalent.
- **Support only** means it can help research, calculate, or prepare an output but cannot replace the resource.
- **No equivalent** means no ready-made match was verified; a custom skill, MCP connector, or repository wrapper is required.

A skill is workflow guidance; a connector supplies live data or controlled actions. Treating those as interchangeable would overstate coverage. Codex results reflect the plugin directory visible to this workspace on the audit date. “Available” does not mean installed, licensed, authenticated, or approved. Claude results use Anthropic's public financial-services repository; partner-built skills may require separate LSEG or S&P data access.

### Main finding

Codex has verified direct connectors for Alpaca, Interactive Brokers, Financial Datasets, YNAB, and a near-match for Salesforce, plus functional plugins for market data, public-equity research, portfolio visibility, accounting, computation, and academic search. Claude has a much broader ready-made **financial workflow** layer in Anthropic's repository—wealth planning, client reviews, proposals, rebalancing, tax-loss harvesting, KYC, equity research, financial modeling, fixed income, and fund administration—but generally lacks direct custody, brokerage-execution, account-aggregation, surveillance, and commercial platform connectors.
