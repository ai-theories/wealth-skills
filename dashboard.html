Frequently asked questions

What is Wealth Skills?

An open-source library that gives AI agents such as Claude Code, Codex and Cursor the workflow knowledge and calculation tools for US wealth management. It has skill packs that tell an agent when a workflow applies, zero-dependency calculation engines, a CLI, MCP servers and this dashboard.

What are Claude skills for wealth management?

Claude skills are SKILL.md files that tell Claude when a workflow applies and which tools to use. Wealth Skills ships nine of them for wealth management: financial planning, portfolio management, trade execution, client onboarding, compliance, CRM, investment research, ultra-high-net-worth planning and fund operations. Each one is backed by calculation code that Claude Code can run through the CLI or MCP servers.

Do these investing skills work with Claude Code, Codex and Cursor?

Yes. The same wealth management skills and investing skills run in Claude Code, Claude Desktop and any MCP client, and in coding agents such as OpenAI Codex, Cursor and Google Antigravity through the command-line interface or the JavaScript library.

Does Wealth Skills place trades or give investment advice?

No. It prepares analysis and order payloads for a licensed professional to review. It never submits orders or moves money, and results that affect a client carry requiresHumanApproval.

How do I connect Wealth Skills to Claude or another MCP client?

Clone the repository and register mcp-servers/universal-wealth-server/index.js as a stdio MCP server with node. It exposes 35 tools. A second server, mcp-servers/sec-iapd-lookup/index.js, looks up investment adviser registrations in SEC IAPD compilation files. See the integration guide.

How much capital loss can be deducted in a year?

Under IRC §1211(b), net capital losses offset up to $3,000 of ordinary income a year, or $1,500 when married filing separately. The rest carries forward under §1212(b) and keeps its short- or long-term character. The Capital Losses & NIIT tab follows the Schedule D Capital Loss Carryover Worksheet.

When does the 3.8% net investment income tax apply?

To the lesser of net investment income or MAGI above $250,000 (married filing jointly or qualifying surviving spouse), $125,000 (married filing separately) or $200,000 (single or head of household). The thresholds are set by statute and not indexed for inflation.

What is the difference between time-weighted and money-weighted return?

Time-weighted return links the sub-period returns between cash flows, so it measures the manager regardless of when money came in or went out. Money-weighted return (XIRR) is the rate that sets the present value of the dated cash flows to zero, so it reflects the investor's own timing.

Does Wealth Skills query FINRA BrokerCheck?

No. FINRA's terms of use prohibit automated access and use with AI tools. Investment adviser registrations are looked up in the daily compilation files the SEC publishes at adviserinfo.sec.gov/compilation; broker-dealer registrations should be checked by hand on BrokerCheck.
